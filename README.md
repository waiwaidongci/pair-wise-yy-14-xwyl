# hxyfront-62013 木结构榫卯构件测绘

源提示词编号：8

落架前体检放行台：按建筑与构件编号录入树种、榫型、截面长宽、裂缝深度、变形值与处置意见。长宽非正整数或变形超过短边十分之一的构件留在待复测，原记录不被覆盖；复测由另一人填写两次读数，两次皆合格才进入可回装清单；树种或榫型改动会使旧结论失效。清单、剖面标记与关联图联动收窄，档案存于本机浏览器（localStorage），关闭再打开历史仍在。

## 代码结构（算法、档案、界面各写一处）

- `src/algorithm.ts` — 算法：正整数判定、变形限值、单次量测判定、复测合格与结论失效推导
- `src/archive.ts` — 档案：记录/复测数据结构、localStorage 持久化、追加式变更（只增不改）
- `src/App.tsx` — 界面：录入台、复测台、联动筛查（清单 + 剖面标记 + 关联图）、历史查看
